# Texts and translations

## Languages and files

- `assets/i18n/ru/` — modern Russian; `assets/i18n/en/` — English; `assets/i18n/ru-old/` — the
  Old Russian layer (pre-reform spelling: ъ, ѣ, і), which falls back on `ru` for any key it lacks
  (most rules and content keys live only in `ru` and are converted for the old speech in code).
- Files by subject: `ui.ftl` (screens), `content.ftl` (cards, relics, potions, foes, moves,
  omens), `rules.ftl` (statuses, keywords, generated rules text, traits), `story.ftl`,
  `voice.ftl` (spoken lines).
- Every new key goes into **both** `ru` and `en` in the same change. Loader warnings
  ("duplicate keys", "fluent syntax errors") at start-up mean a broken file: fix them.

## Fluent pitfalls

- A string literal cannot hold a raw line break: write `{ "\u000A" }`.
- Plural selectors: Russian `[one] [few] *[many]`, English `[one] *[other]`.
- A key name must be unique across the language's files: two foes sharing a move id share its
  name (rename one id).

## Generated text

- Card text is built from the card's effects (`L10n::card_text`, `fx-*` keys) unless a
  `card-<id>-desc` is written by hand.
- An enemy move's hover text is `move-<id>-desc` when written, else built from its effects by
  `L10n::move_text` with `foe-*` keys (`foe-damage-AllFoes`, `foe-hook-<name>`…). A move whose hook
  does something special needs a `foe-hook-<name>` line. The test
  `every_enemy_move_says_what_it_does` fails on any move with nothing to say.
- Marks on a hero show under them when `trait-<flag>` exists (with `-help`); statuses need
  `status-<Kind>` and `status-<Kind>-help`.

## Voice text

Spoken lines are listed in `docs/prompts/voice/*.txt` (see [audio](audio_pipeline.md)); the
old-speech voice text marks stressed vowels in capitals.
